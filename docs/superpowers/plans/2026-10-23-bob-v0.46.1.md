# Bob Provider on v0.46.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` or
> `superpowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reapply Bob JSON and SQLite session support to a local branch based on
GitHub tag `v0.46.1`, then create a local binary and documentation screenshots.

**Architecture:** Keep the current `main` checkout untouched and add Bob to the
release tag's parser registry. The Bob provider combines the existing JSONL
source-set machinery with a read-only SQLite multi-session source set; the
registry continues to drive roots and config overrides.

**Tech Stack:** Go, AgentsView's parser facade, `mattn/go-sqlite3`, testify,
Makefile, Docker, Playwright, and SQLite CLI.

**Spec:** `docs/superpowers/specs/2026-10-23-upstream-v0.46.1-bob-design.md`

## Global Constraints

- Work only on local branch `upstream-v0.46.1-bob`, based on verified tag
  `v0.46.1`; keep current `main`, its untracked helper, and its ignored outputs
  unchanged.
- Preserve `.bob` as the default root. `BOB_DIR` and `bob_dirs` override it.
  JSON discovery descends only under `tmp/**/chats/`; SQLite discovery reads
  `db/bob.db` in read-only mode.
- Preserve task project precedence: `tasks.directory`, then `env.workspace`,
  then a `file:` project identifier. Thread contexts into SQLite source lookup.
- Do not add dependencies, AgentsView archive migrations, or other fork changes.
- Do not push either local branch. Keep the binary and generated images in the
  integration worktree.
- Use a SQLite CLI compatible with the bundled Go SQLite writer for extractor
  tests and screenshots. The test fixture is written by SQLite 3.53.4; CLI
  3.51.0 fails to open it, while CLI 3.53.4 passes. Prepend
  `$(brew --prefix sqlite)/bin` to `PATH` for those commands.
- Use `$(brew --prefix node@22)/bin` first on `PATH` for `make build` and
  `bob --version`; the default Node 16 cannot parse the Bob bundle.

```go
func TestBobProviderResolvesSQLiteTaskWorkspace(t *testing.T) {
	tests := []struct {
		name, directory, projectID, rawEnv, want string
	}{
		{"directory wins", "/dir", "file:/project", `{"workspace":"/env"}`, "/dir"},
		{"env fallback", "", "file:/project", `{"workspace":"/env"}`, "/env"},
		{"file project fallback", "", "file:/project", "{}", "/project"},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			root := t.TempDir()
			dbPath := filepath.Join(root, "db", bobDBName)
			require.NoError(t, writeBobSQLiteFixture(dbPath))
			conn, err := sql.Open("sqlite3", dbPath)
			require.NoError(t, err)
			_, err = conn.ExecContext(t.Context(), `
				UPDATE tasks SET directory = ?, project_id = ?, env = ?
				WHERE id = ?`, tt.directory, tt.projectID, tt.rawEnv, "task-1")
			require.NoError(t, err)
			require.NoError(t, conn.Close())

			provider, ok := NewProvider(AgentBob, ProviderConfig{Roots: []string{root}})
			require.True(t, ok)
			sources, err := provider.Discover(t.Context())
			require.NoError(t, err)
			require.Len(t, sources, 1)
			outcome, err := provider.Parse(t.Context(), ParseRequest{Source: sources[0]})
			require.NoError(t, err)
			require.Len(t, outcome.Results, 1)
			assert.Equal(t, tt.want, outcome.Results[0].Result.Session.Cwd)
		})
	}
}
```

func TestDefault_BobRootAndOverride(t *testing.T) {
	home := canonicalTempDir(t)
	setTestHome(t, home)
	t.Setenv("BOB_DIR", "")
	cfg, err := Default()
	require.NoError(t, err)
	assert.Equal(
		t, []string{filepath.Join(home, ".bob")},
		cfg.ResolveDirs(parser.AgentBob),
	)

	override := canonicalTempDir(t)
	t.Setenv("BOB_DIR", override)
	cfg, err = Default()
	require.NoError(t, err)
	cfg.loadEnv()
	assert.Equal(t, []string{override}, cfg.ResolveDirs(parser.AgentBob))

	legacy := canonicalTempDir(t)
	t.Setenv("BOB_DIR", "")
	cfg = loadMinimalWithConfig(t, map[string]any{
		"bob_dirs": []string{legacy},
	})
	assert.Equal(t, []string{legacy}, cfg.ResolveDirs(parser.AgentBob))
}
